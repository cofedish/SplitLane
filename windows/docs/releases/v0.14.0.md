# SplitLane для Windows — v0.14.0

- DHCPv4 и DHCPv6 исключены из перехвата WinDivert, включая получение адреса после загрузки и продление аренды.
- Добавлен ранний пропуск DHCP до определения процесса и применения правил маршрутизации.
- Удалён скрытый PowerShell-перезапуск интерфейса после обновления. После установки откройте SplitLane вручную.
- Номер версии согласован между Public и Corporate: 0.14.0; источники и ключи обновлений остаются независимыми.

Проверка DHCP на реальном Windows 11 25H2 после перезагрузки и повторный тест Kaspersky ещё предстоят.
Удаление PowerShell устраняет предполагаемый триггер, но отсутствие срабатывания Kaspersky пока не подтверждено.
При обновлении со старого клиента его прежний механизм перезапуска ещё выполняется: для проверки нового механизма сначала установите этот MSI вручную.

Public MSI/EXE не имеют Authenticode-подписи; update manifest подписан существующим ключом Public.
Corporate использует отдельную подпись установщика и манифеста и канал Nexus testing.
