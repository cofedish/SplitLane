# SplitLane для Windows — v0.14.2

Переходная версия для ручной установки перед проверкой обновления до 0.14.3. Windows-приёмка выполняется отдельно.

- Обновление выполняется в фоне службы, не блокируя получение статуса через IPC.
- В настройках отображаются этапы проверки наличия обновления, загрузки с объёмом и процентом, проверки пакета и запуска установки. Процент относится к загрузке, не к выполнению Windows Installer.
- Исправлено наложение кнопок на длинный текст ошибки; ошибка установки сбрасывает состояние ожидания.
- Автор приложения и установщика — cofedish.
- Corporate: диагностика подписи включает код WinVerifyTrust. Для исправления недоверенного корня нужен централизованный trust через GPO, а не исключение антивируса.
- Corporate: подготовлено доверие к следующему сертификату cofedish. Эта переходная сборка подписывается прежним сертификатом; приватные ключи не изменяются. Имя цифровой подписи изменится только в следующем выпуске после доставки доверия и приёмки переходной версии.

Окно может закрыться при замене файлов MSI. После установки откройте SplitLane вручную и проверьте версию. Подтверждение завершения установки определяется новой версией после запуска; 100% скачивания не означает завершение MSI.
