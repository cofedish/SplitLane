# SplitLane для Windows — v0.12.0

## Добавлено

- Доменные политики: `DIRECT`, `PROXY`, `PROXY_ONLY` и `BLOCK`.
- Страница редактирования доменных правил: точные имена, wildcard, выбранное
  приложение или все приложения, включение/выключение и валидация.
- Совместные селекторы приложения, домена, protocol и CIDR в конфигурации.
- Нормализация регистра, завершающей точки и IDN; `*.example.com` соответствует
  поддоменам, но не самому `example.com`.
- Ограниченные DNS evidence с TTL, A/AAAA, CNAME и отказом от угадывания имени
  при нескольких живых доменах на одном IP.

## Исправлено

- Позднее решение `PROXY_ONLY`, истечение NAT и поздние FIN/ACK после CLOSE
  больше не должны переводить распознанный защищённый поток в DIRECT.
- UDP CLOSE не удаляет TCP NAT на совпадающем source port.
- WinDivert shutdown закрывает оба направления, включая ожидающий Receive.
- Обновление списка приложений не очищает выбранную область доменного правила.

## Проверки

До выпуска выполнены 729 Core/Engine тестов и Release build без ошибок и
предупреждений. На рабочей Windows с WinDivert 2.2 правило
`*.example.com -> PROXY_ONLY` проверено для TCP/UDP IPv4 при недоступном proxy,
timeout и неверном пароле: physical Realtek counters и независимый post-routing
PCAP показали 0 исходящих пакетов к origin. Прямой контроль показал 7 пакетов.
Исправный proxy получил `CONNECT www.example.com:80`.

Подробности: `windows/docs/DOMAIN_POLICY_VALIDATION.md`. Результаты GitHub CI
и SHA-256 сборок доступны в связанном workflow run и `SHA256SUMS.txt`.

## Важные ограничения

- `PROXY` сохраняет существующую семантику SplitLane: ошибка proxy не вызывает
  direct retry. `PROXY_ONLY` дополнительно удерживает строгие решения при поздней
  атрибуции и не отменяет их по обычному сроку NAT.
- Нет постоянного WFP/firewall kill switch. При crash, остановке, restart службы
  или загрузке Windows до запуска перехвата защита не гарантируется.
- Имя зависит от наблюдаемого DNS. Уже закешированные ответы, DoH, DoT, ECH,
  прямой IP и неоднозначные shared CDN IP не доказывают домен назначения.
- IPv6 покрыт unit-тестами, но не live-захватом; IPv6 UDP через relay блокируется.
  IPv6 extension headers и фрагментированные TCP DNS требуют отдельной проверки.
- Конфигурация записывается как schema 3. Schema 1/2 читаются новой версией,
  но старый engine не должен принимать schema 3. Перед установкой сохраните копию
  `%ProgramData%\SplitLane\configuration.v2.json` для возврата к прежней версии.
- Бинарные файлы не имеют code signing; Windows SmartScreen может предупредить.
  Сверьте SHA-256 перед установкой.

## Установка

MSI устанавливает engine как службу и включает WinDivert. Portable ZIP требует
запуска `Engine\SplitLane.Engine.exe` от администратора перед открытием приложения.
Этот релиз публикует сборки; установка на тестовой машине в рамках выпуска не выполнялась.
