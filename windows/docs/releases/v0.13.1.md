# SplitLane для Windows — v0.13.1

## Исправлено

- Защищены каталоги службы, хранение proxy credentials и подготовка обновлений,
  выполняемых от SYSTEM; загрузка и установка проверяют происхождение и идентичность пакета.
- Приложение проверяет владельца named pipe перед передачей данных службе.
- DNS evidence принимаются только для соответствующего наблюдаемого запроса;
  ответы и ожидающие запросы ограничены по сроку и объёму.
- Исправлены идентификация TCP/UDP потоков, удержание активных соединений,
  повторное принятие UDP решений и проверка адреса UDP relay.
- Исправлен сбой чтения системных IPv4 DNS resolvers.
- Исправлены гонка завершения проверки UDP identity и устаревший callback,
  который мог заменить новое решение BLOCK на DIRECT.
- Ограничены пути загрузки native библиотек, ресурсы службы и диагностические запросы;
  усилены проверка подписи приложения, обработка фрагментов и изоляция журналов.
- Ключ подписи обновлений изолирован в отдельной CI job;
  минимальная версия bundled .NET runtime — 10.0.12.

- Исправлена подготовка ACL regression test для elevated CI runner: владелец
  тестового пакета назначается явно, проверка отказа сохраняется.

## Проверки

Локально прошли 951 Core/Engine тест и 222 security regression tests
(security tests входят в общий набор), Release build — без предупреждений.
Проверки выполнены 6 октября 2026 года на Windows 11 x64.

На реальной LocalSystem службе с WinDivert проверены TCP соединение дольше
пяти минут, TCP/UDP на одинаковом source port, повторное использование UDP порта,
фильтрация поддельных UDP relay ответов и корреляция DNS ответов.
Захват после перехвата не обнаружил DIRECT пакетов защищённого тестового потока
при работающей службе. После принудительного падения службы обнаружены исходящие
DIRECT TCP SYN; после её запуска proxy path восстановился.

Проверки SYSTEM staging и попытки доступа двух обычных локальных пользователей
выполнялись с безопасным marker artifact. Реальная установка MSI, перезагрузка,
все overload/fragment/IPv6 сценарии и полный security acceptance gate этим
выпуском не подтверждаются. Итоговый runtime security gate остаётся FAIL.
Результаты релизного CI и SHA-256 доступны в workflow и SHA256SUMS.txt.

## Важные ограничения

- Постоянного WFP/firewall kill switch нет. При crash, остановке или restart
  службы, а также до запуска перехвата при загрузке Windows выбранный трафик
  может идти DIRECT. Этот риск подтверждён runtime проверкой и не устранён.
- Имя назначения зависит от наблюдаемого DNS. DoH, DoT, ECH, кешированные ответы,
  прямой IP и неоднозначные shared CDN IP не доказывают домен назначения.
- Полная live IPv6 и fragment validation остаётся незавершённой.
- Бинарные файлы не имеют code signing; Windows SmartScreen может предупредить.
  Подпись update manifest не является Authenticode подписью MSI.
- Перед обновлением сохраните копию
  `%ProgramData%\SplitLane\configuration.v2.json` для возможного возврата.

## Установка

MSI устанавливает engine как службу и включает WinDivert. Portable ZIP требует
запуска `Engine\SplitLane.Engine.exe` от администратора перед открытием приложения.
Релиз включает MSI, portable ZIP, SHA256SUMS.txt и подписанный update manifest.
