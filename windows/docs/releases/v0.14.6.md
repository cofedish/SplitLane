# SplitLane для Windows — v0.14.6

Выпуск для проверки обновления с установленной 0.14.5 через приложение. Функционально соответствует исправленной 0.14.5: сохранены односторонняя привязка прогресс-бара и этапы загрузки/проверки/установки. После установки откройте приложение вручную и проверьте версию.

Публичный updater использует независимый GitHub-канал и прежний ключ подписи манифеста.

Приёмка обновления на Windows-АРМ, DHCP после перезагрузки и отсутствие обнаружения Kaspersky выполняются отдельно.
