# SplitLane для Windows — v0.14.1

Выпуск для проверки обновления с 0.14.0. Сохранены исправления DHCP и установка без скрытого PowerShell-перезапуска интерфейса.

Corporate: добавлена постоянная ссылка `testing/SplitLane-Corp-latest.msi` в Nexus. Она обновляется отдельным заданием разрешения канала, после проверки и переключения подписанного latest.json. Повтор задания восстанавливает ссылку после частичного сбоя; версионированные пакеты не изменяются. Updater продолжает использовать подписанный манифест и версионированный URL.

Windows-приёмка DHCP после перезагрузки, совместимости с Kaspersky и установки обновления ещё предстоит. После обновления откройте окно SplitLane вручную.
