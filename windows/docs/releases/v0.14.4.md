# SplitLane для Windows — v0.14.4

Исправлена ошибка открытия настроек: привязка прогресса загрузки к DownloadPercent теперь односторонняя. Выпуск для первоначальной ручной установки перед проверкой обновления до 0.14.5.

Независимый публичный updater использует GitHub Releases и прежний ключ манифеста.

Проверка обновления на Windows-АРМ, DHCP после перезагрузки и отсутствие обнаружения Kaspersky требуют отдельной приёмки.
