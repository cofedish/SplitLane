# SplitLane для Windows — v0.14.5

Выпуск для проверки обновления с 0.14.4 через приложение. Включает исправление односторонней привязки прогресса; после установки откройте приложение вручную и проверьте версию.

Независимый публичный updater использует GitHub Releases и прежний ключ манифеста.

Проверка обновления на Windows-АРМ, DHCP после перезагрузки и отсутствие обнаружения Kaspersky требуют отдельной приёмки.
