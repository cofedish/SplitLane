# SplitLane для Windows — v0.14.3

Выпуск для проверки обновления с вручную установленной 0.14.2. Сохранены прогресс скачивания и этапы проверки/установки. После установки откройте приложение вручную и проверьте новую версию.

Corporate: цифровая подпись MSI/EXE теперь указывает издателя cofedish. Сертификат перевыпущен на прежний RSA-ключ; ECDSA-ключ подписи манифестов и пароль PFX не менялись. На тестовом АРМ должны быть доверены оба публичных сертификата. Клиентам до 0.14.2 нужна сначала переходная сборка или ручная установка через ИТ.

Существующий корпоративный канал testing и постоянная ссылка Nexus сохраняются. Stable не меняется. Public использует независимый GitHub updater и прежний ключ подписи манифестов.
